# Spec: RepoReaper Developer Diagnostic Assistant

## 1. Overview
RepoReaper is an interactive desktop/web co-pilot built with a retro Windows 95 aesthetic that leverages local Model Context Protocol (MCP) tools to analyze repository health, audit diffs, and inspect terminal crashes.

## 2. Core Capabilities
- **Diff Exorcism:** Runs local git diff and status checks to flag secrets, syntax errors, and forgotten debugging logs.
- **Log Necromancy:** Reads the latest terminal/server error logs and suggests immediate code fixes.
- **Retro Terminal Interface:** A 98.css-styled floating window with a pixelated reaper sprite.
